01 · Overview

项目总览

ecompass 当前已经从一个“想法”推进成了一个具备明确叙事、清晰边界、可做展示、可做众筹包装的项目雏形。它的核心不在于做一个玄学 gadget，而在于把一个有触感的实体物件，和一个足够轻、足够克制、足够能被人真实使用的数字体验连接起来。

这意味着它不是靠伪科学承诺来卖货，而是靠产品叙事、桌面审美、触发动作和短时体验闭环来建立价值感。

一句话定义：ecompass = 一个可触摸的桌面仪式入口，帮助用户 pause / reset / focus。
桌面仪式物 NFC / 触发式入口 轻量数字体验 Kickstarter 叙事化包装 可继续扩展为品牌
02 · Thinking

核心思路与方法论

这一轮最关键的成果，不是多做了几个页面，而是把项目的底层逻辑理顺了。原始方向中真正有价值的部分被保留了下来，风险高、不可持续、容易踩平台边界的部分被明确砍掉。

保留下来的正确判断

  • 用户愿意为“实体触感 + 数字体验”买单。
  • 低复杂度硬件 + 高表达内容，更适合快速验证。
  • 先打穿最小闭环 Demo，再决定要不要放大到众筹或品牌化。

明确砍掉的部分

  • 收割焦虑式叙事。
  • 伪科学承诺与神秘化表达。
  • 靠擦边传播和夸大结果去制造转化。

所以现在的项目思路更稳：用 A 做落地（Desk Ritual Object），用 B 做包装（Mindful Tech Artifact），把 C（AI-guided Reflection Tool）留给后续增强，而不是一开始就把复杂功能和玄学叙事全堆上去。

03 · Market

市场与用户判断

当前市场判断不是“这个罗盘能不能神秘爆卖”，而是欧美 Kickstarter 用户是否愿意为一个有设计感、有仪式感、又不过度神叨的桌面物件买单。结论是：有机会，但前提是叙事要诚实、视觉要高级、体验要具体。

目标用户

  • 对桌面审美敏感的人
  • 对 mindful tech / calm tech 有兴趣的人
  • 愿意为情绪价值和仪式感付费的 Kickstarter 支持者

用户买的不是

  • 不是“算命器”
  • 不是复杂智能硬件
  • 不是治疗或疗愈承诺

用户真正买的是

  • 一个能摆在桌上的真实物件
  • 一个开始 / 收束动作的触发器
  • 一个不重但有感觉的数字回应

也就是说，真正的护城河不会是 NFC 本身，而会是产品叙事、外观语言、内容设计，以及从开箱到使用那一整套体验感。

04 · Positioning

定位与产品方案

这一轮已经把 MVP 的边界定义清楚了：先做一个真实可演示、可测试、可给人上手体验的最小闭环，而不是先去做大而全的品牌幻想。

MVP 应包含

  • 一个可拿在手里的物理载体
  • 手机轻触 / 扫描即可进入网页
  • 网页内至少跑通 Reset / Focus / Reflect 三个场景
  • 可供他人演示和体验的最小闭环

MVP 暂时不做

  • 复杂账号体系
  • 海量 SKU
  • 订阅付费系统
  • 过重的 AI 对话 / 命运导师式体验

这个方案的优点是：打样成本更低、验证链路更短、失败可回收、成功后又能自然扩展到内容包、限定版、联名版，甚至后续品牌化。

05 · Kickstarter

Kickstarter 页面与叙事方案

Kickstarter 这部分已经不只是“写点文案”了，而是完成了完整的页面信息架构和首版汇报文案方向。页面不是从技术炫耀出发，而是按支持者真正会做决策的顺序推进。

页面推荐结构

  • Hero
  • Why Now
  • What ecompass Is
  • How It Works
  • Materials & Form
  • Experience Flow
  • Rewards
  • Timeline / Risks / FAQ / Closing CTA

叙事原则

  • 从体验切入，而不是从技术卖点切入
  • 从真实生活场景建立相关性
  • 全程避免玄学化和疗效承诺
  • 语气保持 honest / calm / tactile / intentional

同时也已经产出首版 Kickstarter copy，包括标题、副标题、长短故事、Reward 层级、FAQ、Risks & Challenges、Timeline 等，可继续进入英文润色和页面实现阶段。

06 · Visual

视觉资产与场景策略

视觉上已经确定不走“神秘疗愈模板”，而是用 Morning / Work / Evening 三联场景去回答产品为什么适合真实生活。这是当前市场表达里很重要的一步，因为它把产品从空泛理念拉回了具体使用语境。

Morning

  • 关键词：begin / pause / intention
  • 强调一天开始前最后一段安静时刻
  • 气氛：柔和、透气、不过度效率化

Work

  • 关键词：reset / focus / return
  • 强调工作中注意力漂移后的回归
  • 气氛：克制、有秩序、非焦虑办公感

Evening

  • 关键词：close the loop / reflect
  • 强调一天结束后的安静收束
  • 气氛：温暖、亲密、不是神秘疗愈

每个场景都已经有较完整的生成 prompt 与验收标准，这意味着视觉生产不需要再从零想，可以直接进入图像生成与筛选环节。

09 · Next

下一步建议

基于当前成果，最合理的下一步不是继续抽象讨论，而是把这套材料推进到更接近外部可用的状态。优先级建议如下：

优先推进

  • 生成 / 筛选 Why Now 三张正式视觉图
  • 把 Kickstarter 页面内容进一步落成对外预览版
  • 确定 Hero 主图与产品 hero 文案
  • 明确 reward / 价格 / 首批交付逻辑

同步准备

  • 整理一套可发给协作者的 review package
  • 继续推进实体样品 / NFC 路径
  • 补充实际拍摄或 AI 视觉生产
  • 为 Kickstarter 账号和发布节奏做准备
当前阶段最重要的不是再扩写概念，而是把已经清楚的方向变成更可预览、更可评审、更可外发的版本。
